## Overview
This project demonstrates the use of the jQuery library to simplify DOM manipulation, handle events, and create animations. It is split into 5 parts connected via a Bootstrap Navbar.

## Project Structure
1. `index.html` (Part 1) - Setup, Basic Selectors, and CSS Manipulation.
2. `part2.html` (Part 2) - Visibility, Fade, and Slide effects.
3. `part3.html` (Part 3) - DOM element addition/removal, attribute modification, and live form interactions.
4. `part4.html` (Part 4) - Basic, sequential, and combined animations using `.animate()`.
5. `part5.html` (Part 5) - Mini Project: Interactive Accordion Menu utilizing jQuery `.slideToggle()`.

## Usage
Open any of the HTML files in a browser to test the features. The files use CDN links for Bootstrap 5 and jQuery 3.7.1, so an active internet connection is required.
